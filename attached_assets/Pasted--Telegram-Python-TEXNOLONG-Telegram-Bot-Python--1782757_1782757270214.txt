У тебя есть существующий код Telegram-бота на Python (репозиторий: TEXNOLONG/Telegram-Bot-Python). Нужно его доработать по следующим пунктам.

1. МИГРАЦИЯ БАЗЫ ДАННЫХ

Заменить bot_data.json на SQLite (или PostgreSQL через Supabase).

Создать таблицы:

users (id, telegram_id, ip_address, registration_date, tier, subscription_until, banned, test_count_today)

history (id, user_id, target_url, test_type, start_time, end_time, rps, success_rate, p95, p99)

admin_log (id, admin_id, action, timestamp)

Написать миграцию для переноса существующих данных из JSON в новую БД.

2. СИСТЕМА РЕГИСТРАЦИИ ЧЕРЕЗ БРАУЗЕР

Убрать регистрацию внутри Telegram (она не даёт IP-адрес).

Добавить команду /register, которая генерирует уникальную ссылку: https://ваш-домен/register/{user_id}.

Создать Flask-страницу с кнопкой «Подтвердить регистрацию». При нажатии:

Фиксировать IP-адрес через request.remote_addr (или X-Forwarded-For).

Сохранять telegram_id и ip_address в БД.

Отправлять пользователю в бота уведомление: «Регистрация завершена» (без указания IP).

Без регистрации пользователь не может запускать тесты.

3. РАЗДЕЛЕНИЕ LITE И PRO РЕЖИМОВ

LITE (бесплатный):

Трафик идёт с IP-адреса пользователя (зафиксированного при регистрации).

Бот генерирует Python-скрипт с подставленными параметрами: target_url, user_ip, duration=60.

Скрипт скачивается пользователем и запускается локально.

Ограничения: 100 RPS, только HTTP GET, максимум 60 секунд.

После завершения скрипт отправляет отчёт на /report эндпоинт бота.

PRO (платная подписка):

Трафик идёт с распределённых агентов (воркеров), развёрнутых на VPS.

Пользователь отправляет цель через бота, агенты начинают флудить.

Поддерживаются: TCP SYN, UDP-флуд, HTTP/2, ICMP.

Подмена IP-отправителя (spoofing) через AF_PACKET.

Без ограничений по времени и RPS.

Отчёт включает: RPS, P95/P99, статусы ответов, обнаружение Cloudflare/Akamai.

4. МОДУЛЬ ОБХОДА ЗАЩИТ

Добавить в класс стресс-тестирования:

Ротация User-Agent: база из 100+ строк (Chrome, Firefox, Safari, Edge). Ротация для каждого запроса.

Автоматическое определение Cloudflare: анализ заголовков CF-Ray, cf-request-id. Если защита найдена — переключение на медленный режим с куками и HTTP/2.

Прокси-поддержка: для PRO-режима использовать список SOCKS5/HTTP-прокси. Автоматическая смена прокси при 403/429.

Эмуляция человека: случайные паузы (джиттер), заголовки Accept-Language, Accept-Encoding.

5. МОНЕТИЗАЦИЯ ЧЕРЕЗ CRYPTOBOT

Интеграция с CryptoBot (USDT, TRC20/BSC).

Цены:

PRO 7 дней — $2.99

PRO 30 дней — $7.99

PRO 90 дней — $19.99

При успешной оплате обновлять subscription_tier и subscription_until в БД.

Команда /buy — выбор подписки и генерация счёта.

Команда /status — показать текущий тариф и оставшееся время.

6. АДМИН-ПАНЕЛЬ

Сделать через команды бота (не через веб, чтобы не усложнять):

/stats — общая статистика (пользователи, подписки, тесты за день).

/ban @username — заблокировать пользователя (установить banned=true).

/unban @username — разблокировать.

/setprice <tier> <usdt> — изменить цену подписки (хранить в БД или .env).

/broadcast <текст> — массовая рассылка всем зарегистрированным пользователям.

/logs — последние 50 действий (админ-логи).

7. БЕЗОПАСНОСТЬ

Все секреты вынести в .env (BOT_TOKEN, ADMIN_ID, CRYPTO_TOKEN, DB_URL, SECRET_KEY).

Добавить .env в .gitignore.

Валидация URL: запрет на localhost, 127.0.0.1, 10.0.0.0/8, 192.168.0.0/16, правительственные домены (.gov, .mil).

Лимит: для LITE — не более 3 тестов в день на пользователя.

Чёрный список (бан) через админ-команды.
